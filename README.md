# PEcb10. Протокол видеовстречи

Ассистент принимает запись встречи, делит речь по говорящим и собирает протокол. Подходят файлы `mp3`, `mp4` и `mkv`.

Сервер для этого проекта не нужен. Сервис поднимается через Docker Compose на одной машине.

## Состав

| Каталог | Что это |
| --- | --- |
| `stt_analyse-main` | Telegram-бот. Папка `data`, AssemblyAI, OpenAI и PostgreSQL |

Подробности запуска: [ассистент](stt_analyse-main/README.md).

## Куда попадают файлы

1. Запись, положенная в `stt_analyse-main/data`, остаётся в этой папке. Рядом появляются `<имя>.transcript.txt`, `<имя>.protocol.md` и `<имя>.protocol.docx`.
2. Запись из Telegram скачивается во временный каталог. В чат уходят транскрипт и протокол docx, затем временный каталог удаляется. Исходный файл из чата на диск не пишется.
3. Текст транскрипта и протокола в обоих случаях сохраняется в PostgreSQL, таблица `video_audits`, поле `analysis`.

## Быстрый запуск

Из каталога `stt_analyse-main`:

```bash
copy .env.example .env
docker compose up --build -d
```

В `.env` нужны `TELEGRAM_BOT_TOKEN`, `ASSEMBLYAI_API_KEY` и `OPENAI_API_KEY`. В контейнере адрес базы подменяется на `db`, каталог `data` смонтирован в `/app/data`.

Остановка: `docker compose down`.

## Что не входит в репозиторий

Файл `.env` с ключами, записи встреч, транскрипты и протоколы. Шаблон переменных лежит в `stt_analyse-main/.env.example`.
